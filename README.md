# Task tracker

Простой список задач, выполненный в рамках обучения frontend разработке

## Реализованный функционал

- доболение/удаление задач
- изменение статуса выполнения задачи нажатием на нее
- темыная и светлая темы

## Запуск

Требуется совместимая с проектом LTS-версия Node.js.

```bash
npm ci
npm run dev
```
